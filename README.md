# MouseLens

Небольшая экранная лупа для Windows 10 (версия 2004 и новее) / Windows 11 x64. Запустите `dist/MouseLens.exe` или назначьте этот файл на кнопку мыши. Установка и права администратора не нужны.

- Движение мыши: лупа следует за курсором.
- Колесо вверх/вниз: увеличение/уменьшение (от 1× до 12×).
- Стрелки вправо/влево: увеличить/уменьшить ширину на 40 пикселей.
- Стрелки вверх/вниз: увеличить/уменьшить высоту на 40 пикселей.
- Любая другая клавиша или нажатие кнопки мыши: закрыть лупу. Это нажатие также получает приложение под лупой, чтобы можно было сразу продолжить работу.
- Повторный запуск при уже открытой лупе закрывает её.

Начальный размер — 640×320, увеличение — 2×. При выходе размер и увеличение сохраняются в `MouseLens.ini` рядом с программой. Если папка недоступна для записи, лупа работает без сохранения. Удалите этот файл для сброса настроек.

Цвет рамки задаётся в секции `[Lens]` параметром `BorderColor=#377DDCFF`. Формат — `#RRGGBBAA`: красный, зелёный, синий и непрозрачность. `FF` — непрозрачная рамка, `80` — примерно 50%, `00` — невидимая. Например, `#AA000080` — полупрозрачная тёмно-красная рамка, а `#AA000000` — полностью прозрачная. Также принимается `#RRGGBB` (без прозрачности). При ошибке в значении используется исходная синяя рамка. Прозрачность влияет только на рамку; содержимое лупы остаётся непрозрачным. Настройки применяются при следующем запуске. Если параметра нет, программа добавляет его автоматически.

Пример настроек: `MouseLens.example.ini`. Его можно скопировать в `dist/MouseLens.ini`. Личный файл настроек не отслеживается Git.

В увеличенном изображении курсор не рисуется: виден один обычный системный указатель.

Захват выполняется через Windows Graphics Capture с обязательным `IsCursorCaptureEnabled=false`, масштабирование и рамка — шейдером Direct3D 11, вывод — через DirectComposition. Изображение остаётся в видеопамяти: нет копирования скриншотов в оперативную память, масштабирования через GDI и обработки миллионов пикселей процессором каждый кадр. Использовавшийся ранее DXGI Desktop Duplication мог возвращать уже встроенный в картинку курсор, поэтому он заменён.

Прозрачное окно занимает текущий монитор и исключено из захвата через `WDA_EXCLUDEFROMCAPTURE`. Прямоугольник лупы, его положение, изображение и рамка рисуются в одном GPU-кадре; окно не перемещается при каждом движении курсора. Очередь ограничена одним кадром, вывод синхронизирован с частотой монитора, координаты курсора читаются непосредственно перед подготовкой кадра. Устаревшие события изменения размеров и масштаба не создают очередь перерисовок. Windows Graphics Capture получает явный запрет захвата указателя до начала сеанса; системный курсор не скрывается и не подменяется.

В зависимости от версии Windows и разрешений система может показывать свою рамку индикации захвата по краю монитора. Эта рамка не относится к цвету `BorderColor`.

Поддерживается несколько мониторов. Окно ограничивается текущим монитором. На защищённом рабочем столе UAC, при захвате защищённого видео и поверх некоторых окон с повышенными правами действуют ограничения Windows.

## Сборка

Переносимый LLVM-MinGW: https://github.com/mstorsjo/llvm-mingw/releases/tag/20261020

Распакуйте `llvm-mingw-20261020-ucrt-x86_64.zip` в `.tools`, затем выполните `powershell -ExecutionPolicy Bypass -File build.ps1`. Другой путь к компилятору можно передать параметром `-Compiler`. Скрипт собирает ресурсы, самостоятельный EXE и запускает проверки геометрии и масштаба. Сторонние DLL рядом с EXE не нужны.

`geometry.h` содержит независимую от Windows логику. `main.cpp` реализует окно и ввод, `capture.h` — захват, `renderer.h` — вывод через Windows API; для Wayland потребуется отдельная реализация этих частей.

`test-render.ps1` собирает и запускает интеграционный тест: 120 шагов движения и изменения размеров, включая 1880×1600, обновление шахматного фона под лупой, проверка каждого исходного пикселя на самозахват, прозрачности рамки и области вне лупы. Отдельная проверка курсора использует положительный контроль: намеренно включает захват указателя и обнаруживает его пиксели, затем отключает и проверяет, что все пиксели под видимым системным курсором совпадают с фоном. Чтение пикселей с GPU используется только в тестовой сборке. Тест не перемещает курсор и не вводит нажатия в другие приложения; на несколько секунд показывает собственные тестовые окна под текущим положением указателя. Для проверки курсора указатель должен оставаться внутри тестового фона.

`test-render.ps1 -Benchmark` дополнительно измеряет производительность при размерах 640×320, 1880×1600 и 2400×1600. Время CPU-подготовки и отправки команд (`mean`) отделено от времени шага с ожиданием слота вывода (`frame-with-pacing`). Последнее измеряет темп отправки кадров, а не задержку от движения мыши до появления пикселей на экране.
